# Learnova — Mobile E-Learning UI/UX Prototype

A complete **mobile e-learning UI/UX project** designed in Figma, covering the full design process from user research and experience planning to wireframes, iterative interface development, usability testing, and a high-fidelity interactive prototype.

Learnova is designed to provide students with a clean, accessible, and engaging learning experience where they can discover courses, manage their learning, track progress, attend live sessions, earn certificates, and interact with learning-focused features from one mobile platform.

## Project Overview

**Learnova** is a fictional e-learning mobile application created to provide students with a structured and engaging online learning experience.

The design focuses on making it easy for users to:

- Discover courses
- Enrol in learning content
- Continue ongoing courses
- Watch course videos
- Attend live learning sessions
- Track learning progress
- View schedules
- Maintain learning streaks
- Receive certificates
- Manage subscriptions and payments
- Access notifications
- Manage their profile and settings

The goal was not only to create visually polished screens, but to design a complete experience based on user needs, behaviour, usability, accessibility, feedback, and testing.

---

## UX Design Process

The Learnova project follows a complete user-centred design process.

```text
User Research
      ↓
User Persona
      ↓
Empathy Map
      ↓
User Journey
      ↓
Information Architecture
      ↓
User Flow
      ↓
Wireframes
      ↓
Initial UI Design
      ↓
Interactive Prototype
      ↓
End-User Testing
      ↓
Feedback Analysis
      ↓
UI Iterations
      ↓
Final High-Fidelity Prototype
```

This process helped ensure that design decisions were based on how users would actually interact with the application rather than focusing only on appearance.

## User Persona

A user persona was developed to represent the target learner and guide design decisions throughout the project.

The persona helped identify areas such as:

- Learning goals
- User expectations
- Motivations
- Frustrations
- Digital behaviour
- Accessibility needs
- Preferred learning experience

Design decisions were then evaluated against these user needs.

---

## Empathy Mapping

An empathy map was created to better understand the learner from several perspectives.

The process considered what the user may:

- Think
- Feel
- See
- Hear
- Say
- Do

It also helped identify user pains and goals.

This provided additional context when designing navigation, course discovery, progress tracking, and other learning features.

## Usability & Accessibility

Learnova was designed around three key goals:

### Usability

The interface aims to make common actions easy to understand and complete.

This includes:

- Clear navigation
- Consistent components
- Recognisable icons
- Logical screen hierarchy
- Predictable interactions

### Accessibility

Accessibility was considered throughout the design process to make the interface easier to use for a wider range of learners.

Considerations included:

- Readable typography
- Clear visual hierarchy
- Understandable navigation
- Consistent controls
- Appropriate spacing
- Visual clarity

### Engagement

The platform includes features intended to encourage continued learning, including:

- Progress tracking
- Streaks
- Clips
- Certificates
- Live sessions
- Notifications
- Course discovery

## User Testing

The prototype was tested with end users to understand how well the interface matched user expectations.

Testing focused on areas such as:

- Navigation
- Usability
- Visual clarity
- Ease of completing tasks
- User expectations
- Engagement
- Overall interface experience

Feedback was collected and analysed instead of treating the first prototype as the finished product.

---

## Feedback-Driven Refinement

Results from user testing were used to refine later versions of the interface.

The process followed:

```text
Design
   ↓
Prototype
   ↓
Test
   ↓
Collect Feedback
   ↓
Identify Issues
   ↓
Improve
   ↓
Create New Iteration
```

This iterative workflow allowed the final prototype to evolve from the initial design rather than simply reproducing the first idea.
